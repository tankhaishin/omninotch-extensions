# OmniNotch extensions

Live Activities for the Mac notch. Every extension here shows up in the OmniNotch store at
[mactoro.com/omninotch/extensions](https://mactoro.com/omninotch/extensions) with an Install button.

An extension is a folder with two files: `manifest.json` (what it is) and `run` (any script that prints a little
JSON). OmniNotch runs it, draws it in the notch, and asks the person to allow it before it ever runs.

- **Make one:** read [GUIDE.md](GUIDE.md). Five minutes, any language.
- **Share it:** read [CONTRIBUTING.md](CONTRIBUTING.md), then open a pull request.
- **Browse:** `extensions/<author>/<name>/`. The ones in `extensions/mactoro/` come with OmniNotch.

Extensions are fan-made unless they say otherwise. An extension that shows another company's data is not made or
endorsed by that company.
